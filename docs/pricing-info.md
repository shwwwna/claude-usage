# Claude Pro Pricing & Session Capacity

Reference data for understanding your quota consumption across different Claude models.

## Models Overview

### Haiku 4.5 (~30% of Sonnet cost)

- **Per 5-hour window**: ~150 messages
- **Weekly capacity**: ~36–44 full sessions
- **Cost efficiency**: Lowest cost per message; ideal for high-volume, lower-complexity tasks

### Sonnet 4.6 (baseline)

- **Per 5-hour window**: ~45 messages
- **Weekly capacity**: ~9–11 full sessions
- **Cost efficiency**: Balanced performance and cost; recommended default for most work

### Opus 4.6 (3–5x Sonnet cost)

- **Per 5-hour window**: ~9–15 messages
- **Weekly capacity**: ~2–3 full sessions at peak; ~4–6 off-peak
- **Cost efficiency**: Highest capability; use for complex reasoning, edge cases, specialized tasks

## Reading the Data

- **Per 5-hour window** = typical capacity within one session window
- **Weekly capacity** = approximate number of complete session cycles you can run in a week
- Numbers are estimates based on typical usage patterns and message complexity
- Actual usage depends on your interaction patterns, prompt length, and response complexity

## Using This Data

When planning your quota:
1. Identify which models you'll use for this week
2. Cross-reference your session count with the model's capacity
3. Adjust pacing to fit your model distribution
4. Use the tracker's pacing controls to align with your expected usage patterns
