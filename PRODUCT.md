# Product

## Register

product

## Users

Claude users who need to track API quota usage in real time. They glance at the tracker while working (quick status check) and also do thoughtful analysis (weekly pacing, quota planning). They paste usage text from claude.ai/settings/usage and want instant clarity on whether they're on pace.

## Product Purpose

A minimal PWA that parses Claude usage data and visualizes quota against elapsed time. Shows session and weekly quotas, calculates target % based on remaining time, and surfaces whether usage is on-target, over, or under. Enables users to make fast pacing decisions without cognitive load.

## Brand Personality

Restrained, utilitarian, transparent. Like Claude itself: confident without decoration, clear without noise.

## Anti-references

- Generic SaaS dashboards (hero metrics, gradient cards, identical grids)
- Gamified or playful interfaces
- Decorative patterns or visual flourish
- Modals as first resort
- Anything that slows comprehension

## Design Principles

1. **Essential only** — Every element earns its space. Remove anything decorative or redundant.
2. **Clarity first** — Data and status must be grasped in a glance; analytical deeper-dives should feel natural, not cluttered.
3. **Transparent defaults** — Sensible pacing presets, clear reset times, no hidden logic.

## Accessibility & Inclusion

WCAG AA standard. Support reduced motion preferences. Ensure color alone never conveys status (pair with text/badges always).
