How the Quota System Works

Session & Weekly Limits

5-hour rolling session window + separate weekly cap. Claude.ai and Claude Code share the same pool.

Conversation Cost Escalation

Message 1 in a new conversation: ~500 tokens. Message 30 in same conversation: 40,000+ tokens (entire history re-processed each turn).

Peak Hours Impact

Peak hours (05:00–11:00 PT) reduce effective capacity. Off-peak usage allows higher throughput.

High-Leverage Habits

  • Start new conversations frequently — 5 conversations of 10 messages each cost far less than one 50-message conversation.
  • Default to Sonnet — Opus costs 3–5x more. Use it only for complex reasoning, architecture, nuanced writing.
  • Use Projects with cached documents — Upload reference materials once; they don't count against limits on reuse.
  • Batch questions into single messages — Group related questions to reduce back-and-forth.
  • Write complete prompts upfront — Include all context and constraints in one message.
  • Keep CLAUDE.md lean (<150 lines) — Every word loads on every session. Cut anything non-behavioral.
  • Use /clear aggressively — Start fresh to avoid old history eating tokens.
  • Use .claudeignore — Prevents Claude from reading unneeded files.
  • Point to specific files, not whole repo — Scoping prevents hundreds of file reads.
  • Use plan mode for non-trivial work — Prevents wrong paths and wasted tokens.

Anti-Patterns to Avoid

  • Don't keep one mega-conversation — it re-sends full history every message.
  • Don't default to Opus for everything.
  • Don't re-paste documents — use Projects to cache them.
  • Don't send vague one-liners that need clarification rounds.
  • Don't let Claude explore the whole repo unscoped.
  • Don't overload CLAUDE.md with aspirational text.
  • Don't use @-file for large documents — reference paths instead.
  • Don't ignore the usage dashboard.
  • Don't run Claude Code in loops without rate-limit handling.
